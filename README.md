# Basic Keyword Frequency Analyzer

This example demonstrates a fundamental concept behind many SEO tools: keyword frequency analysis. It takes a block of text (simulating website content) and a list of target keywords, then calculates how many times each keyword appears. This helps digital marketers understand keyword density and optimize content for search engines.

## Language

`python`

## How to Run

Save the code as `seo_keyword_analyzer.py`.
Run from your terminal: `python seo_keyword_analyzer.py`
